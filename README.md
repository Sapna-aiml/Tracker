# 💰 Expense Tracker

A simple **Expense Tracker application developed using Python** to record, manage, and track daily expenses.

## 📌 Project Overview

This project is a Python-based Expense Tracker that helps users maintain their daily expense records in an organized way. Users can add expenses, view their records, and calculate total spending.

## 🎯 Objectives

- Track daily expenses
- Record expense details
- Manage spending information
- Calculate total expenses
- Improve basic financial management

## ✨ Features

- ➕ Add Expense
- 📋 View Expenses
- 💰 Calculate Total Expenses
- 🏷️ Expense Categories
- 🔄 Multiple Transactions
- ⚠️ Basic Input Validation

## 🛠️ Technologies Used

- Python
- Functions
- Variables & Data Types
- Conditional Statements
- Loops
- Lists
- User Input

## 🧠 Python Concepts Used

- `if-else`
- `while` loops
- Functions
- Lists
- Arithmetic Operations
- User Input
- Basic Data Handling

## ⚙️ How It Works

1. Start the Python application.
2. Select an option from the menu.
3. Enter the expense details.
4. The expense is recorded.
5. View all recorded expenses.
6. Check the total amount spent.
